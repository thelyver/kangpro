# ✅ 3. 요양보호사 대상 KSP(Korean for Specific Purposes) 1차 커리큘럼 v1.0

타깃: E-9·D-10 외국인 근로자 / 요양보호사 취업 희망자  
목표: _현장에서 당장 사용 가능한 실전형 한국어 + 안전·감정노동 대응 + 보고체계 기반 언어능력 강화_  
특징: ETRI 발화평가 + 시나리오 기반 Long-turn + 직무 코퍼스 기반 표현 구성

---

## 📘 모듈 구성(6개 모듈 / 30차시)

---

## 모듈 1. 기본 직장 한국어 + 요양시설 환경 이해 (5차시)

학습 목표: 요양시설 환경·역할·기본 표현 익히기

### 주요 학습 요소

- 요양보호사 역할 소개
    
- 어르신 호칭·기본 예절 한국어
    
- 시설 구조 용어(복도, 사무실, 생활실, 간호사실 등)
    
- 교대시간, 보고체계 기본 표현
    
- 어르신과의 기본 의사소통(천천히 말하기·확인 질문 등)
    

### Long-turn 시나리오

- “출근 → 인수인계 → 생활실 확인”
    

---

## 모듈 2. 돌봄 일상 업무 한국어 (6차시)

학습 목표: 돌봄 기본 키워드 중심 일상 대화 수행

### 주요 학습 요소

- 식사·배식·물·약 관련 표현
    
- 세면·목욕·체위변경·이동 돕기
    
- 기저귀 교체 안내 표현
    
- 반복 요청·거부 대응 표현
    
- 어르신 불편 호소(아파요, 답답해요, 움직이기 어려워요)
    

### Long-turn 시나리오

- “식사 보조 → 약 확인 → 휴식 안내 → 화장실 이동”
    

---

## 모듈 3. 건강·의료 관련 KSP 한국어 (6차시)

학습 목표: 간단한 건강 체크 및 간호사 보고 능력

### 주요 학습 요소

- 체온·혈압·맥박 체크 언어
    
- 통증 부위·강도 묻기
    
- 증상(기침, 호흡곤란, 어지러움 등) 파악 표현
    
- 응급 상황 기본 대응 언어
    
- 간호사에게 정확하게 보고하기
    

### Long-turn 시나리오

- “어르신 증상 확인 → 데이터 체크 → 간호사 보고”
    

---

## 모듈 4. 감정·행동 대응 한국어 (5차시)

학습 목표: 치매·고령자 돌봄 시 발생하는 감정·행동 관리

### 주요 학습 요소

- 반복 질문 대응
    
- 화남·불안·짜증 표현 완충
    
- 안정시키기(말투·속도·톤)
    
- 갈등 상황 회피 대화
    
- 강한 반말·투정·고함에 대한 대응
    

### Long-turn 시나리오

- “불안한 어르신 진정 → 상황 설명 → 보호자·간호사와 공유”
    

---

## 모듈 5. 안전·사고 예방 KSP 한국어 (4차시)

학습 목표: 낙상·배뇨·욕창 등 위험 상황 의사소통

### 주요 학습 요소

- 낙상 위험 알림(미끄러워요, 조심하세요)
    
- 이동 보조 안전 표현
    
- 긴급 상황 호출
    
- 시설 안전 규칙 언어
    
- 기기·장비 관련 지시 이해
    

### Long-turn 시나리오

- “이동 보조 중 위험 발생 → 즉각 대응 → 관리자 보고”
    

---

## 모듈 6. 보고·기록 KSP 한국어 (4차시)

학습 목표: 요양 보호 업무의 핵심인 보고·기록 능력 강화

### 주요 학습 요소

- 5W1H 기반 보고
    
- “상황·행동·조치·결과” 구조
    
- 간단한 업무일지 작성
    
- 교대 시 인수인계 핵심 언어
    
- 관찰 보고·변화 추적 표현
    

### Long-turn 시나리오

- “근무 종료 인수인계 → 주요 변화 보고 → 문서 기록”
