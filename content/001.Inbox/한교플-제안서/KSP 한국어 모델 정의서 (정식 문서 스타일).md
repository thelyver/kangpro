# 📘 KSP(Korean for Specific Purposes) 모델 정의서 (DUNET Official)

## 1. 모델 개요

KSP(Korean for Specific Purposes)는 특정 산업·직무·업무 상황에서 요구되는 실제 한국어 사용 능력을  
체계적으로 교육하기 위해 설계된 목적 기반 실전형 한국어 모델이다.  
범용 한국어 중심의 기존 교육과 달리, KSP는 현장의 안전, 작업 지시, 보고 체계 등  
업무 수행에 직접 연결되는 언어 능력을 중심으로 구성된다.

---

## 2. KSP의 핵심 원리

### 2-1. Needs-based Language Design

- 산업별·직무별 언어 요구를 기반으로 커리큘럼 구성
    
- 위험 상황, 작업 흐름, 직장 문화 등 실제 의사소통 장면을 반영
    

### 2-2. Task-based Communication

- 실제 업무 수행을 그대로 학습 과제로 설계
    
- ‘작업 지시 수행 → 안전 확인 → 보고’ 등의 실제 업무 흐름 기반 학습
    

### 2-3. Corpus-driven Approach

- 산업별 KSP 코퍼스 구축
    
- 직무별 전문용어, 사투리·반말, 비상 상황 표현까지 포함
    

### 2-4. Performance Evaluation

- 문법·어휘 점수가 아닌 실제 역할 수행 능력 중심 평가
    
- ETRI 발화 평가(정확/오류/자유대화)와 Long-turn 문맥 평가 모델 적용
    
- “지시 이해 → 응답 → 수행” 기반 평가 체계 구축
    

---

## 3. KSP의 구성 요소 (모듈 구조)

### 3-1. 공통 모듈 (Universal KSP)

- 현장 기본 표현 (안전·보고·지시)
    
- 산업 안전 표준 표현
    
- 기초 직장 커뮤니케이션
    

### 3-2. 산업별 모듈 (Sector-specific KSP)

- 제조업 KSP
    
- 건설업 KSP
    
- 요양보호사 KSP
    
- 서비스업 KSP
    
- 농·어업 KSP
    

각 모듈에는 실제 현장의 어휘, 지시문, 위험 표현, 사투리/속어까지 반영.

### 3-3. 상황별 모듈 (Situational KSP)

- 출근·교대·보고·회의
    
- 기계고장/비상상황 대응
    
- 팀 소통, 갈등 조정
    

---

## 4. KSP의 AI 기술 적용 구조

### 4-1. ETRI 발화 평가 기반 KSP 대화 엔진

- 문법 오류 인식
    
- 지시 수행 가능 여부 판단
    
- 시나리오 내·외 대화 상황 분류
    

### 4-2. KSP 시나리오 기반 Long-turn Conversation Model

- 작업 흐름 중심 연속 대화
    
- 주제 전환 인식
    
- 맥락 기반 대화 유지
    

### 4-3. 산업별 KSP 코퍼스 학습 엔진

- 실제 현장 언어 데이터를 기반으로 모델 fine-tuning
    
- 사투리/속어/전문 용어 포함
    

---

## 5. KSP가 제공하는 핵심 효과

### ✔ (1) 즉각적 생산성 향상

작업 지시 이해→오류 감소→작업 속도 증가

### ✔ (2) 안전사고 감소

산업재해 14% 중 언어 장벽 기여 비중 해소

### ✔ (3) 정착 및 이직 감소

직장 문화 이해·소통 가능 → 적응 속도 향상

### ✔ (4) 기업·정부·지자체의 정책 정합성 충족

E-9 특화훈련, 사회통합, 산업별 교재 정책과 완전 정합

---

## 6. 결론

KSP는 단순한 한국어 교육이 아니라  
외국인 근로자의 안전·생산성·정착을 개선하는 ‘산업 기반 언어 솔루션’이며,  
디유넷이 제공하는 AI 기반 한국어교육 플랫폼의 핵심 가치입니다.
