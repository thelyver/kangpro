강프로님,  
**ESP(English for Specific Purposes)**는 언어교육 분야에서 가장 중요한 개념 중 하나이며,  
**외국인 근로자 한국어 교육(KSP)**를 기획하는 지금 이 맥락에 _정확하게 적용될 수 있는 모델_입니다.

아래에서 강프로님 스타일에 맞춰 **단계별·명확·실무 중심**으로 정리해 드립니다.

---

# ✅ 1. ESP의 정의

**ESP = English for Specific Purposes (특수 목적 영어)**  
→ 특정 직업, 산업, 상황에서 필요한 영어 능력을 키우는 **목적 지향형 언어교육 모델**입니다.

즉, “일반 영어(General English)”와 달리,  
**직무·산업·전문 분야에 필요한 실제 언어 사용 능력**을 훈련합니다.

---

# ✅ 2. ESP의 핵심 특징

### ✔ (1) 일반 언어가 아닌 ‘목적 기반’

- 업무 수행
    
- 안전
    
- 전문 용어
    
- 산업 환경의 문맥  
    을 중심으로 실제로 쓰는 영어를 교육합니다.
    

### ✔ (2) 직무, 산업, 학문 분야별로 세분화

예를 들어:

|ESP 유형|설명|
|---|---|
|**EAP (Academic Purposes)**|대학·연구·논문 작성을 위한 영어|
|**EOP (Occupational Purposes)**|직장·직무 수행 중심 영어|
|**EHP (Health Purposes)**|의료 전문 영어|
|**EMP (Medical Purposes)**|의료진이 쓰는 전문 의료 영어|
|**EESP (Engineering Purposes)**|엔지니어링 분야 영어|
|**ENP (Nursing Purposes)**|간호사 영어|

→ 산업별로 매우 세밀하게 전문화됨.

---

# ✅ 3. ESP가 등장한 배경

- 글로벌 비즈니스 확대
    
- 산업별 전문기술 가속화
    
- 일반 영어로는 업무 수행이 불가능한 실무 환경 증가
    
- 대학·기업의 “성과기반 언어 교육” 요구 증가
    

즉, “문법/회화 중심” 일반 영어로는 **현장에서 즉시 효과가 나지 않기 때문**입니다.

---

# ✅ 4. ESP의 교육 구성 방식

### **① Needs Analysis(요구 분석)**

→ 어떤 작업 상황에서 어떤 언어를 사용하는가?

### **② Target Situation Analysis(목표 상황 분석)**

→ 실제 업무 상황을 그대로 언어훈련에 반영

### **③ 직무 기반 코퍼스 구축**

→ 산업별 대화, 문서, 현장 지시문 수집 후 언어 모델링

### **④ Task-based Learning(업무 기반 학습)**

→ 실제 업무 시나리오에 기반한 대화 중심 학습

### **⑤ Performance-based Assessment**

→ 시험이 아닌 “업무 수행 능력” 평가

---

# ✅ 5. ESP의 대표적인 예시

- 항공조종사 영어 (Aviation English: ICAO 기준 있음)
    
- 항해·선박 영어(Maritime English)
    
- 의료진 영어(Medical English)
    
- 간호사 영어(Nursing English)
    
- IT 개발자 영어(Tech English)
    
- 호텔/관광 서비스 영어(Service English)
    

→ 모두 "시험 점수가 아니라 **업무 수행 능력**"이 목적입니다.

---

# ✅ 6. KSP(특수 목적 한국어)와 연결되는 핵심 논리

강프로님이 기획하시는 한국어 교육 플랫폼은 **ESP와 동일한 철학**을 가집니다.

|ESP|KSP|
|---|---|
|항공·의료·기술 분야 영어|제조·건설·요양·서비스 한국어|
|업무·안전 중심|현장 지시·안전·보고 중심|
|Task-based 실전 중심|시나리오 기반 발화 평가|
|산업별 코퍼스 구축|ETRI 기술 + 산업별 KSP 코퍼스|

특히 ESP는  
→ **“현장에서 즉시 쓰는 언어” = 생산성 향상**  
에 초점을 둡니다.

이는 디유넷 KSP 한국어의  
→ “산업재해 예방 + 생산성 향상”  
과 완전히 정합합니다.

# ✅ 7. 슬라이드나 문서에 쓰기 좋은 요약 문구

**ESP(English for Specific Purposes)**

> “특정 직무·산업·목적에 필요한 실전 언어 능력 향상을 목표로 하는 전문 영어 교육”

**핵심 포인트:**

- 목적 기반
    
- 직무 기반
    
- 실제 수행·상황 중심
    
- 산업별 코퍼스
    
- 실전 커뮤니케이션 능력
